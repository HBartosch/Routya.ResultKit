# 🤝 Contributing to Routya.ResultKit

Thanks for helping us improve **Routya.ResultKit**, a minimal and consistent result wrapper for APIs.

---

## 📌 You Can Contribute By:

- Improving response formatting or error reporting
- Adding fluent or extension APIs
- Enhancing support for `ProblemDetails`
- Expanding the test suite
- Improving documentation examples

---

## 📐 Guidelines

- Focus on API clarity and simplicity
- Return `Result<T>` or `ProblemResult` consistently
- Avoid overloading the package with framework-specific logic

---

## ✅ PR Checklist

- [ ] Add/adjust tests for new or changed behavior
- [ ] Document public API changes in the README if relevant
- [ ] Use the [ResultKit PR Template](https://github.com/HBartosch/Routya.ResultKit/blob/main/.github/PULL_REQUEST_TEMPLATE.md)

---

## 📣 Reporting a Vulnerability

If you discover a security vulnerability in any Routya.ResultKit package, please **do not open a public GitHub issue**. Instead, please use the GitHub Security Advisory ["Report a Vulnerability"](https://github.com/HBartosch/Routya.ResultKit/security/advisories/new) tab.
We will send a response indicating the next steps in handling your report, we will then keep you informed of the progress towards a fix.
